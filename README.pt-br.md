<h2>Visão Geral do Projeto</h2>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Este projeto é uma página de perfil responsiva construída com <strong>LESS</strong>.
  Ele demonstra o uso de variáveis, mapas, mixins, media queries e escaping.
  Os mapas do LESS são utilizados para centralizar e gerenciar a paleta de cores,
  facilitando a aplicação e alteração de temas em toda a folha de estilo.
  Também foram integrados os <strong>Feather Icons</strong> para elementos de UI,
  e o plugin <strong>less-watch-compiler</strong> foi utilizado para automatizar
  o processo de compilação.
</p>
<p>
    🔗 Demonstração: <a href="https://less-profile-page-asrieldreemurrgm.vercel.app/" target="_blank">Ver na Vercel</a>
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3 / LESS</li>
  <li>Feather Icons</li>
  <li>LESS Watch Compiler</li>
  <li>copyfiles (copiar HTML e imagens)</li>
  <li>chokidar-cli (observar alterações nos arquivos)</li>
  <li>concurrently (executar múltiplos scripts simultaneamente)</li>
</ul>
<h2>Como Executar</h2>
<ol>
  <li>Clone o repositório.</li>
  <li>Instale as dependências com <code>npm install</code>.</li>
  <li>Execute o script de desenvolvimento com <code>npm run dev</code> para observar e compilar LESS, copiar HTML e imagens.</li>
  <li>Ou execute <code>npm run build</code> para criar o build uma vez para deploy.</li>
  <li>Abra <code>build/index.html</code> (ou <code>index.html</code> no dev) no navegador para visualizar a página de perfil.</li>
</ol>
